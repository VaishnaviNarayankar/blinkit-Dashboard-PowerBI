# Blinkit Sales Performance Analysis Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze sales performance across stores, products, and regions. The project focuses on identifying sales trends, evaluating business performance, and understanding customer purchasing patterns through data visualization.

## Project Objectives
- Track sales performance across different stores and products.
- Identify top-selling product categories and best-performing outlets.
- Analyze customer preferences and purchasing behavior.
- Understand regional sales patterns and variations.
- Generate actionable insights to support data-driven business decisions.

## Key Insights
- **Store Performance:** Evaluate and compare sales across different store locations.
- **Category Analysis:** Identify top-performing product categories.
- **Product Analysis:** Understand product-level sales trends and performance.
- **Customer Preferences:** Analyze customer purchasing patterns and preferences.
- **Regional Analysis:** Identify regional sales trends and demand patterns.
- **Fat Content Distribution:** Uses a donut chart to compare sales contributions from Low Fat and Regular products.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization

## Project Outcome
Developed an interactive dashboard that transforms raw sales data into meaningful visual insights, helping businesses monitor performance, identify trends, and make informed decisions.
